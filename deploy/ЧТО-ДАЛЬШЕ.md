# Что дальше делать (деплой фронта)

## Уже сделано в репо

- **deploy/docker-compose.yml** — только сервис `front`, сеть `education-network` (external).
- **deploy/.env.example** — FRONT_IMAGE, FRONT_IMAGE_TAG.
- Workflow по пушу в main/develop собирает образ и пушит в ghcr.io; по SSH выполняет `docker compose pull front && docker compose up -d front` в `DEPLOY_PATH`.

## Что сделать на своей машине

1. Добавить секреты в GitHub (репо front-new): DEPLOY_HOST, DEPLOY_USER, DEPLOY_SSH_KEY, DEPLOY_PATH (путь к папке deploy на VPS, например `/opt/front-new/deploy`).
2. Запушить код в main — образ соберётся и запушится; деплой по SSH сработает только после шагов на сервере ниже.

## Что сделать на сервере (один раз)

1. Установить Docker и Docker Compose (если ещё нет).
2. Склонировать репо front-new в `/opt/front-new` (или другой каталог).
3. Перейти в папку deploy: `cd /opt/front-new/deploy`.
4. Создать `.env`: `cp .env.example .env`, указать `FRONT_IMAGE` (ghcr.io/ВАШ_ОРГАНИЗАЦИЯ/front-new) и `FRONT_IMAGE_TAG=latest`.
5. Создать `.env.front` с тремя переменными NEXT_PUBLIC_GRAPHQL_URL, NEXT_PUBLIC_UPLOAD_URL, NEXT_PUBLIC_SITE_URL (https://www.new.standart82.ru/...).
6. Убедиться, что сеть бэкенда есть: `docker network ls | grep education-network`.
7. Запустить фронт: `docker compose up -d`.
8. В конфиге nginx бэкенда заменить upstream frontend на `server education-center-front:3000;` и выполнить перезагрузку nginx (в папке деплоя бэкенда): `docker compose exec nginx nginx -s reload`.

После этого https://www.new.standart82.ru отдаёт фронт (/) и бэкенд (/graphql, /upload). При пуше в main workflow обновит образ и перезапустит контейнер фронта.
